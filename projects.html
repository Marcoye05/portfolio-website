My Projects

Project 1: Computer Building

This project involved trying to build a computer from scratch. I learned about the different components of a computer and how they work together to create a functioning system. I also learned about the importance of compatibility between components and how to troubleshoot issues that may arise during the building process.

Project 2: Web Development

This project involved creating a personal portfolio website using HTML and CSS. I learned about the structure of a website, how to use different HTML tags to create content, and how to style the website using CSS.

Project 3: Stakeholder Identification and Analysis

This project involved identifying and analyzing stakeholders for a hypothetical project. I learned about the different types of stakeholders, their interests and influence on the project, and how to effectively communicate with them. This course is from Intro to project management.

Project 4: Implementing EIGRP into ipv4

This project involved implementing EIGRP into an ipv4 network. I learned about the different routing protocols and how to configure EIGRP on routers. I also learned about the importance of network topology and how to troubleshoot issues that may arise during the implementation process. This course is from advanced networking.

Project 5: Many Faces of Spoofing

This project involved learning about the different types of spoofing attacks and how to prevent them. I learned about IP spoofing, email spoofing, and DNS spoofing, as well as the potential consequences of these attacks. I also learned about different security measures that can be implemented to protect against spoofing attacks. This course is from Intro to computer security.
